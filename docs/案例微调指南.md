# FANS 案例微调指南

**写给佳宜**：以后看到网站上有案例名字错了、文案要改、或者别的细节问题，不用每次都跟我说改 HTML。按照下面这几种方式选一种就行。

---

## 三种方式

### 方式 1 · 直接改 cases.json（推荐）

打开下面这个文件：

```
fans-website/assets/data/cases.json
```

它长这样：

```json
{
  "cases": [
    {
      "id": "01",
      "name": "SKYWORTH创维",
      "section": "科技智造",
      "industry": "科技",
      "cover_image": "assets/cases/case_01_SKYWORTH创维.jpg",
      "detail_folder": "assets/cases/case_01",
      "editable": true
    },
    ...
  ]
}
```

**可以改的字段**（改完告诉我，或者截图发我帮你重生成网站）：

| 字段 | 含义 | 改起来影响 |
|------|------|-----------|
| `name` | 案例名称（卡片+模态窗） | 改名字即可 |
| `section` | 6 行业分类 | 改卡片所属分类 |
| `industry` | 细分行业 | 卡片副标签 |
| `services` | 服务项列表 | 仅 records |
| `style_tags` | 设计风格标签 | 仅 records |
| `highlight` | 一句话描述 | 仅 records |

修改后告诉我「cases.json 已经改了」，我会把改动同步到 project.html 并重新部署。

---

### 方式 2 · 在对话里直接跟我说

遇到错别字或名字错误的，直接这样发：

> 「case 19 的印力集团应该是华润万象生活」
> 「case 27 的亚迪小筑图片位置不对」

我在下一轮回复里改完直接告诉你结果。

**如果你在公司，能直接发我截图**——我可以照着图直接定位和改，比看 cases.json 更快。

---

### 方式 3 · 改 HTML 源码直接同步

如果你是开发者、或者习惯 VSCode 自己改，可以直接打开 `fans-website/project.html`：

| 想改什么 | 搜这个字段 |
|---------|----------|
| 案例名字 | `<div class="case-card-name">XXX</div>` |
| 案例行业细分 | `<div class="case-card-industry">XXX</div>` |
| 6 行业分类 | `data-section="XXX"` |
| 模态窗标题 | `<h2 class="case-modal-title">XXX</h2>` |
| 详情图 | `<div class="case-modal-gallery">...img src="..."...</div>` |

改完保存，我会让本地服务自动重启看到效果。再告诉我重新部署即可。

---

## 几个约定

- **客户名**：保持真实、精确（华润万象生活 ≠ 印力集团，这是不同的公司）
- **6 行业分类**严格用这 6 个标签字面值：
  - 科技智造
  - 企业/商业
  - 公共事业
  - 零售/餐饮
  - 生活方式/时尚
  - 文化/公益
- **case id**（01、02、…）一旦定了不要改。改 id 会导致详情图关联断裂
- **缩略图文件名** 也不要改（`case_NN_客户名.jpg`），改了图就显示不出来了

---

## 上下游文件依赖

```
cases.json              ←  你直接改这个
↓
project.html            ←  cases-grid + 模态窗从 project.html 渲染
assets/cases/case_NN/   ←  详情图文件夹（不要删、不要改名）
FANS公司简介案例_元数据_v1.json   ←  AI 用的元数据（备用）
```
